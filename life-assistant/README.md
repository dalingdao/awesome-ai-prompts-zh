## 1. 旅行规划助手

### 描述
生成完整的旅行行程规划。

### Prompt 模板
```
你是一位资深旅行规划师，精通 [目的地] 的旅游资源。

旅行信息：
- 目的地：[城市/国家]
- 出发地：[城市]
- 出发日期：[日期]
- 旅行天数：[天数]
- 人数：[成人 X 人，儿童 X 人]
- 预算：[总预算]
- 旅行偏好：[文化探索/自然风光/美食体验/休闲度假/亲子]
- 不喜欢的：[避免事项]

请生成完整旅行攻略：

1. 行程总览（每天主题 + 时间安排）
2. 每日详细行程：
   - 上午（景点 + 交通方式 + 预计花费）
   - 午餐推荐（餐厅名 + 人均 + 推荐菜）
   - 下午
   - 晚餐推荐
   - 住宿建议（酒店名 + 价位区间）
3. 预算明细表
4. 实用 Tips（当地交通、电话卡、天气、禁忌）
5. 景点预订信息和注意事项
6. 应急信息（大使馆、医院、报警电话）

输出格式：可打印的 PDF 友好格式
```

## 2. 健康饮食计划师

### 描述
根据个人情况生成个性化饮食计划。

### Prompt 模板
```
你是一位注册营养师，精通膳食搭配和健康管理。

个人信息：
- 性别：[男/女]
- 年龄：[岁]
- 身高体重：[cm/kg]
- 日常活动量：[久坐/轻度活动/中度活动/高强度]
- 健康目标：[减脂/增肌/控糖/均衡营养/改善亚健康]
- 饮食偏好：[素食/清真/过敏食物/不爱吃的食物]
- 特殊状况：[孕期/慢性病/运动恢复期，可选]

请生成一周饮食计划：

每天包含：
- 早餐（食材 + 做法简述 + 热量）
- 上午加餐
- 午餐
- 下午加餐
- 晚餐

每天热量目标：[X] kcal
三大营养素比例：蛋白质 X% / 碳水 X% / 脂肪 X%

额外提供：
1. 一周采购清单（分类：蔬果/肉蛋奶/主食/调料）
2. 替代方案（如果买不到某种食材）
3. 营养补充建议
4. 一周食谱总览表格
```

## 3. 家庭收纳整理顾问

### 描述
提供专业的家居收纳整理方案。

### Prompt 模板
```
你是一位专业整理师，受近藤麻理惠方法论训练。

空间信息：
- 房间类型：[全屋/厨房/衣柜/书房/客厅/儿童房]
- 面积：[平方米或简要描述]
- 目前最大的问题：[描述]
- 家庭成员：[人数 + 年龄段]
- 预算：[收纳用品预算]

请提供收纳整理方案：

1. 整理策略（先处理哪个区域？顺序和理由）
2. 断舍留清单（每个品类：哪些扔/哪些留/哪些需要补充）
3. 分区规划（用文字描述每个区域的功能和存储方案）
4. 收纳用品推荐（具体产品名称/类型 + 预算）
5. 整理步骤（按天/半天为单位的行动计划）
6. 维护计划（如何保持不复乱？每周 15 分钟维护法）
7. 常见错误和避免方法
```

## 4. 健身训练计划师

### 描述
生成个性化健身训练计划。

### Prompt 模板
```
你是一位 NSCA 认证私人教练。

训练者信息：
- 性别：[男/女]
- 年龄：[岁]
- 身高体重：[cm/kg]
- 健身目标：[增肌/减脂/体能提升/塑形/健康维持]
- 训练水平：[新手/有一定基础/进阶]
- 每周可训练天数：[天]
- 每次训练时长：[分钟]
- 训练场地：[健身房/家中/户外]

附加：
- 渐进超负荷计划（每周如何增加强度）

## 5. 每日效率规划师

### 描述
规划高效的一天。

### Prompt 模板
```
你是一位时间管理教练，精通 GTD、番茄工作法和精力管理。

今日信息：
- 日期：[今天日期]
- 可用时间段：[如 9:00-18:00 是工作时间，晚上有 2 小时自由]
- 今日必须完成：[列出 3-5 件重要任务]
- 今日希望完成：[列出 3-5 件次要任务]
- 今天的精力预期：[高/中/低]
- 已知干扰：[如下午有会、容易犯困等]

请帮我规划今天：

1. 时间块安排（按 30 分钟为单位）
   - 标注：🔴 深度工作 / 🟡 管理任务 / 🟢 休息
   - 使用番茄钟（25分钟专注 + 5分钟休息）
2. 优先级排序（解释为什么这样排）
3. 精力管理建议（什么时候做什么类型的任务最高效）
4. 可能的中断预案（如被同事打断怎么处理）
5. 晚间回顾模板（每天 5 分钟自查）

输出格式：清晰的文本时间线
```

## 6. 人际关系沟通助手

### 描述
帮助处理各种社交场景的沟通。

### Prompt 模板
```
你是一位沟通教练和心理咨询师。

场景描述：[详细描述你要应对的社交场景]
对方是谁：[关系 + 性格特点]
你的目标：[你希望达成什么结果]
你担心的：[最担心的冲突或困难]

请帮我设计沟通方案：

1. 沟通策略（整体思路 + 为什么选择这个策略）
2. 开场白（2-3种版本）
3. 主体内容：
   - 核心表达要点（用 '我' 而非 '你' 的句式）
   - 可能遇到的问题 + 应对话术
4. 倾听策略（怎么让对方觉得被理解）
5. 收尾方式（如何确认双方达成一致）
6. 不合适的话术（哪些话绝对不能说？为什么？）
7. 后续跟进建议
```

### 使用示例
<longcat_arg_value>场景：想请室友降低晚上打游戏音量，但怕影响关系
对方：室友，性格直爽但比较自我
目标：让对方主动在晚上11点后戴耳机
你担心：对方觉得你事儿多，影响和谐的室友关系
```

## 7. 财务管理助手

### 描述
帮助个人或家庭管理财务。

### Prompt 模板
```
你是一位 CFP 认证财务规划师。

财务信息：
- 月收入：[金额]（收入来源：工资/副业/投资）
- 固定支出：[房租/贷款/保险等]
- 可变支出：[餐饮/交通/购物等]
- 现有储蓄：[金额]
- 负债情况：[金额 + 利率]
- 财务目标：[如：1年内存 6 个月应急资金 / 5 年内买房 / 还清贷款]
- 风险偏好：[保守/平衡/激进]

请制定财务规划：

1. 月度预算表（50/30/20 法则或自定义比例）
2. 支出优化建议（哪些可以省？具体怎么省？）
3. 储蓄计划（每月存多少？多久达成目标）
4. 债务偿还策略（雪球法 vs 雪崩法，选哪个？为什么？）
5. 应急资金配置建议（几个月的花费？放在哪？）
6. 入门投资建议（匹配风险偏好的方案）
7. 自动理财设置建议（如何设置让理财自动化）
```

## 8. 睡眠改善顾问

### 描述
帮助改善睡眠质量。

### Prompt 模板
```
你是一位睡眠医学顾问，精通 CBT-I（失眠认知行为疗法）。

睡眠信息：
- 通常上床时间：[时间]
- 通常入睡时间：[需要多久才能入睡]
- 夜间醒来次数：[次数]
- 早晨醒来时间：[时间]
- 起床后的感觉：[困倦/清醒/疲惫]
- 当前影响睡眠的因素：[压力/刷手机/环境噪音/咖啡因等]
- 已尝试的方法：[列已经试过但没用或效果不佳的方法]
- 健康情况：[某些疾病可能影响睡眠]

请制定睡眠改善计划：

1. 睡眠评估（你的睡眠质量评分 + 原因诊断）
2. 睡眠卫生习惯优化清单（每个习惯的具体操作）
3. 睡前 1 小时作息表（精确到每 15 分钟）
4. 睡眠限制疗法方案（如果适用）
5. 认知调整（关于睡眠的错误观念纠正）
6. 放松技巧（渐进式肌肉放松、4-7-8呼吸法详细步骤）
7. 21 天改善追踪表
8. 什么时候应该就医（红旗信号提醒）
```

## 9. 购物决策助手

### 描述
帮助做出理性的购买决策。

### Prompt 模板
```
你是一位消费心理学专家，帮助人们做出理性购买决策。

购买决策：
- 想买的东西：[产品名称]
- 价格：[金额]
- 同类替代品：[列举其他选项]
- 购买原因：[为什么想要这个？]
- 预算状况：[这笔钱在你的月度预算中属于什么级别？]
- 使用频率预期：[每天用/偶尔用/不确定]

请帮我分析：

1. 需求评估（这是 need 还是 want？打分 1-10）
2. 产品对比表（这个产品 vs 替代品，含 5-8 个维度）
3. 性价比分析（每元获得的价值）
4. 购买时机建议（现在买还是等打折？什么时候最便宜？）
5. 使用场景预判（买回来后真实使用频率预估）
6. 替代方案（如果不买这个，省下的钱可以做什么？）
7. 决策框架：
   - 如果 [条件A]，建议购买
   - 如果 [条件B]，建议等一等
   - 如果 [条件C]，建议不要买

最后给出我的建议：🟢 推荐 / 🟡 可以再想想 / 🔴 不建议
```

## 10. 情绪管理日记

### 描述
用 AI 辅助情绪日记，增强自我觉察。

### Prompt 模板
```
你是一位正念教练和情绪管理专家。

今天的情绪状态（简要描述）：
[用几句话描述今天发生了什么 + 你的感受]

请根据我的描述，生成今日的情绪日记模板：

1. 🌡️ 情绪评分（0-10 分，0=极度负面，10=非常愉悦）：
2. 🎯 今天的主要情绪是：[帮识别核心情绪，如焦虑/失落/愤怒]
3. 💭 情绪触发分析（发生了什么→我的解读→我的情绪反应）：
4. 🔍 我的思维模式觉察（是否有灾难化/过度概括/非黑即白思维？）
5. ✅ 今天做得好的地方（至少找 3 件）：
6. 🙏 感恩记录（今天值得感谢的 3 件事）：
7. 🌱 明天的微行动（明天可以做的 1 件小事来改善状态）：
8. 💌 给自己的一句话（温暖、肯定的自我对话）：

最后：基于 CBT 的认知重构练习——
"我的自动化思维是：[____]，有没有其他更平衡的解释？[____]"
```

## 11. 家电选型顾问

### 描述
帮助选购合适的家电产品。

### Prompt 模板
```
你是一位家电测评专家，精通各类家电的技术参数和实际使用体验。

我需要购买：[品类：如冰箱/洗衣机/空调/扫地机器人等]
预算：[金额]
使用场景：[家庭人数/房间面积/使用频率]
目前看中的型号：[如果有的话]
特别关注：[省电/静音/智能/容量等]

请提供选购指南：

1. 核心选购参数说明（哪些参数最重要？怎么看？）
   - 不要沉迷于跑分，关注实际体验
2. 我的需求分析（根据场景，我最应该关注的 3 个维度）
3. 推荐方案（3 个价位，各推荐 1-2 款）
   - 最佳性价比款
   - 品质升级款
   - 旗舰体验款
4. 品牌口碑和售后服务对比
5. 购买时机建议（什么时候最便宜？）
6. 安装和使用注意事项
7. 买之前要确认的 5 个问题（防止踩坑）
```

## 12. 综合生活顾问日报

### 描述
生成个性化的每日生活建议。

### Prompt 模板
```
你是一位全能生活顾问，精通养生、效率管理和生活美学。

个人信息：
- 年龄：[岁]
- 职业：[职业]
- 居住城市：[城市]
- 当前季节：[季节]
- 今天的状态：[精力/情绪简要描述]
- 今天的目标：[1-3件事]

请生成今日个性化建议：

1. ☀️ 晨间建议（起床后做什么？5分钟例行程序）
2. 🍽️ 今日食谱灵感（推荐一种当季食材的简单做法）
3. 💪 运动建议（今天适合什么运动？时长？在家就能做的）
4. 📚 学习/成长（今日一个微学习主题 + 推荐资源）
5. 🧘 放松建议（今天适合什么放松方式？）
6. 🌙 睡前建议（今晚的放松仪式）
7. 📌 今日金句（一句话，温暖有力量）
8. 🎲 今日小挑战（一个走出舒适区的小事）

风格：温暖、有信息量、不鸡汤、接地气。像朋友在跟你聊天。
```

---

> 🏡 **生活智慧：** 好的生活不是做更多的事，而是把重要的事做好。模板只是工具，真正的改变来自每天微小的行动。
