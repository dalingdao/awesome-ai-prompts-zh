## 1. 数据报告自动生成器

### 描述
根据原始数据生成专业的数据分析报告。

### Prompt 模板
```
你是一位资深数据分析师，精通 [领域] 业务分析。

数据信息：
- 数据来源：[数据库/API/Excel/CSV]
- 数据时间范围：[起止日期]
- 数据字段说明：[字段名 + 含义]
- 数据样本（前 10-20 行）：[粘贴数据]

分析目标：[想从数据中知道什么？]

请生成包含以下部分的完整报告：

1. 执行摘要（300字内，关键发现 + 建议）
2. 数据概览（数据量、时间范围、关键字段分布）
3. 核心指标分析（含同比/环比变化）
4. 深度洞察（至少 3 个有数据支撑的洞察）
5. 问题诊断（数据中暴露的问题和风险）
6. 行动建议（具体、可执行的改进建议）
7. 附录（方法论说明、数据局限性）

风格：高管汇报风格，结论先行，数据支撑
```

## 2. SQL 查询助手

### Prompt 模板
```
你是一位 SQL 专家，精通 [MySQL/PostgreSQL/SQL Server/BigQuery]。

需求：[用中文描述你想要查询的数据]

表结构：
[粘贴相关表的 CREATE TABLE 语句或字段描述]

请提供：
1. 完整的 SQL 查询语句
2. 逐行解释 SQL 逻辑
3. 索引建议（如果查询涉及大数据量表）
4. 查询性能预估和优化建议
5. 测试数据示例（生成一些 mock 数据 + 预期输出）

注意：
- 使用标准 SQL（注明是否有数据库方言特定语法）
- 复杂查询使用 CTE（公共表表达式）提高可读性
- 添加必要的注释
```

### 使用示例
```
需求：查询上月每个用户的总消费金额，按金额从高到低排列，只显示消费前 100 名
表结构：
orders: order_id, user_id, amount, order_date, status
users: user_id, name, register_date
```

```
- 测试变量：[描述改了什么]

- 核心指标：[主要指标 + 护栏指标]

| 版本 | 用户数 | 转化数 | 转化率 |
|------|--------|--------|--------|
| A    | [数据] | [数据] | [数据] |
| B    | [数据] | [数据] | [数据] |

请分析：
1. 统计显著性（Z 检验 + p 值）
2. 效果和置信区间
3. 样本量充足性检验
4. 结果可靠性检查（SRM 检查、新奇效应排除）
5. 细分分析（不同用户群是否有不同效果）

```

```
需求：
- 播报内容：[每日/每周/每月数据报告]
- 播报渠道：[邮件/企业微信/钉钉/飞书]

1. 播报模板设计
   - 标题格式 + 日期变量
```
