## 1. 小红书爆款标题生成器

### 描述
为小红书内容生成高点击率标题，覆盖多种爆款风格。

### Prompt 模板
```
你是一位专注小红书平台的内容运营专家，擅长创作高点击率标题。

任务：为以下内容生成 10 个小红书爆款标题

内容主题：[输入内容主题]
目标受众：[输入目标受众描述]

要求：
- 每个标题不超过 20 个字
- 使用数字、emoji、悬念感等爆款技巧
- 覆盖不同风格：干货型、情感型、好奇型、对比型
- 标注每个标题使用的技巧标签
- 按预估点击率从高到低排列
```

### 使用示例
```
内容主题：学生党平价护肤
目标受众：18-25岁女大学生，预算有限

输出示例：
① 💰50元搞定全套护肤｜学生党亲测有效！（数字+干货）
② 室友以为我偷偷医美了…其实只花了30块！（悬念+对比）
③ ‼️别再乱买护肤品了！这3样就够了（情绪+数字）
```
