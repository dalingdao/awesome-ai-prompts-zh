## 1. 品牌定位策略生成器

### 描述
为品牌制定差异化定位策略。

### Prompt 模板
```
你是一位品牌战略顾问，曾服务过多个知名品牌。

品牌信息：
- 品牌名称：[名称]
- 行业：[行业]
- 核心产品/服务：[描述]
- 目标用户：[画像]
- 现有竞品：[列举 3-5 个]
- 品牌现状：[初创/转型/升级]

请制定品牌定位策略，包含：
1. 定位声明（一句话，包含目标用户+品类+差异点）
2. 品牌价值金字塔（功能价值→情感价值→精神价值）
3. 品牌调性关键词（5个 + 解释）
4. 与 TOP 3 竞品的差异化分析
5. 品牌传播核心信息屋（Message House）
6. 定位验证方法（如何测试定位是否有效）
```

```
3. 爆款商品分析（TOP 10 SKU）
4. 用户行为洞察（新老客占比、复购分析）

6. 问题和改进点（3-5 个需要优化的地方）

```
